# 📌 Projetos em Destaque

## 🚚 RocketLog API
API REST para gerenciamento de entregas desenvolvida durante a formação da Rocketseat.

**Principais funcionalidades**

- Cadastro de usuários
- Autenticação com JWT
- Controle de entregas
- Histórico de movimentações
- Validação com Zod
- Criptografia de senhas
- Testes automatizados
- Docker + PostgreSQL + Prisma ORM

**Tecnologias**

Node.js • TypeScript • Express • Prisma ORM • PostgreSQL • Docker • JWT • Bcrypt • Jest • Supertest • Zod

API REST para **solicitação de reembolso**, desenvolvida durante a Formação Full Stack da Rocketseat.

O projeto permitiu aplicar na prática conceitos de desenvolvimento backend, autenticação, validação, persistência de dados e upload de arquivos.

### Principais conceitos

* API REST
* Autenticação com JWT
* Criptografia de senhas com Bcrypt
* Validação com Zod
* Upload de arquivos com Multer
* Prisma ORM
* Middlewares
* Tratamento global de erros
* CORS

### Tecnologias

`Node.js` `TypeScript` `Express` `Prisma` `JWT` `Bcrypt` `Zod` `Multer`

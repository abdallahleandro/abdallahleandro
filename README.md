### 📌 Projetos em Destaque

#### 🍽️ [Restaurant Orders API](https://github.com/abdallahleandro/restaurant_api)
API RESTful completa em **TypeScript** para gerenciamento de mesas, sessões de atendimento, produtos e pedidos.
- **Destaques:** Modelagem relacional com **Knex.js** (Migrations & Seeds), validação rigorosa de entradas com **Zod**, ativação nativa de *Foreign Keys* no SQLite e cálculo automatizado de contas via funções agregadas em SQL.
- **Techs:** Node.js, TypeScript, Express, Knex.js, SQLite, Zod.

#### 🎫 [Support Ticket API](https://github.com/abdallahleandro/Projeto_API)
API para controle de chamados de suporte técnico com CRUD completo.
- **Destaques:** Construída utilizando **Node.js Nativo** (sem frameworks) para consolidação dos fundamentos da web, manipulação de *Streams/Buffers*, requisições assíncronas e persistência local JSON.
- **Techs:** Node.js, JavaScript (ES6+), Insomnia.
